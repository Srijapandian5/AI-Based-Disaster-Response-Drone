# AI-Based-Disaster-Response-Drone
An autonomous F450 quadcopter system designed for waypoint payload delivery (up to 500 g) and real-time aerial survivor detection using a Pixhawk 2.4.8 flight controller (ArduPilot + Neo-M8N GPS) paired with a Seeed Studio Jetson Nano 4GB (CUDA-accelerated YOLOv8 + Raspberry Pi Camera Module 2).
